Apakah pesanan langsung diproses setelah checkout?

Belum. Checkout hanya menyiapkan detail pesanan dan mengarahkannya ke WhatsApp. Pesanan berlaku setelah admin mengonfirmasi harga, ketersediaan, dan detail pengerjaan.

Apakah website menerima pembayaran otomatis?

Belum. Website versi ini tidak memproses pembayaran dan tidak menyimpan data transaksi di server. Metode pembayaran dibicarakan langsung dengan admin.

Apakah harga di website sudah final?

Harga yang ditampilkan adalah estimasi contoh. Admin akan memberikan konfirmasi harga final sebelum kamu menyetujui pesanan.

Apakah saya harus memasukkan password akun?

Tidak. Jangan masukkan password atau OTP ke formulir website. Jika detail akses dibutuhkan, bicarakan secara aman dengan admin dan pertimbangkan risiko keamanan akun.
